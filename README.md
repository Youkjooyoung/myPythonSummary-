- Python 3.11 (Anaconda `py311` 가상환경)
- 주요 라이브러리: `opencv-python`, `matplotlib`, `ultralytics`, `schedule`

> 용량이 큰 파일(YOLO 모델 `*.pt`, 영상 `*.mp4`·`*.avi`, 실행 결과 `runs/`)은 `.gitignore`로 업로드에서 제외했습니다.
> YOLO 모델은 코드를 실행하면 자동으로 다운로드됩니다.

왜 분류 모델 학습이 가장 중요할까

앞 단계가 전부 여기로 모여요

촬영(v02_1~3), 증강(v02_4), 라벨링(v02_5)은 모두 학습에 넣을 데이터를 만드는 일이에요. 학습을 해야 이 데이터가 쓸모를 갖습니다.

쓰는 사람에서 만드는 사람으로

v03 실습은 남이 학습시킨 yolo11n.pt를 불러다 쓴 거예요. 학습은 내가 정한 클래스(예: 안경착용)를 구분하는 나만의 모델을 만드는 일입니다.

확인할 게 가장 많아요

데이터셋 구성, epoch마다 바뀌는 loss와 정확도, 결과 그래프까지 단계마다 볼 것이 있어요. 블로그 캡처가 가장 많은 것도 그래서예요.

v02_3_schedule.py
# 사진 캡쳐 간격 설정
interval_time = 5

# 파일명에 / : 는 쓸 수 없다 → 숫자와 _ 만
timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")

# 5초마다 capture_image 실행
schedule.every(interval_time).seconds.do(capture_image)
while True:
    schedule.run_pending()
    time.sleep(1)

기억할 것

  • cv2.VideoCapture(0)로 카메라를 열고, cap.read()로 한 장을 찍어요. 다 쓰면 꼭 cap.release().
  • read()는 (성공여부, 이미지) 두 개를 돌려줘요. 성공했을 때만 저장합니다.
  • 찍은 시간을 파일명으로 쓰면 이름이 겹치지 않고, 언제 찍었는지도 알 수 있어요.
  • schedule로 일정 간격 자동 촬영. 학습용 사진을 많이 모을 때 유용해요.

# alpha: 픽셀에 곱하는 값 / beta: 더할 밝기
img_bright = cv2.convertScaleAbs(img, alpha=1, beta=50)

h, s, v = cv2.split(img_hsv)

기억할 것

  • OpenCV는 색 순서가 BGR, matplotlib은 RGB. 화면에 띄울 때 cvtColor(..., COLOR_BGR2RGB)가 필요해요.
  • 색상 360°를 OpenCV는 0~179로 저장해서 % 180으로 한 바퀴 돌려요.
  • plt.tight_layout()은 결과엔 영향이 없고, 칸 사이 간격만 보기 좋게 맞춰 줘요.
  • 학습에서 train 정확도만 오르고 val이 멈추면(과적합) 증강으로 데이터를 늘리는 게 첫 번째 해결책이에요.

폴더 만들 때 주의

  • 폴더 이름이 그대로 클래스 이름이 돼요. 결과에도 이 이름이 찍혀요.
  • 폴더·파일 이름은 영어로 쓰는 게 안전해요. 윈도우에서 한글 경로는 OpenCV가 못 읽는 경우가 있어요.
  • val에는 train에 없는 다른 사진을 넣어야 진짜 실력을 잴 수 있어요.
  • Roboflow에서 내보낼 땐 분류용 Folder Structure 형식을 고르면 이 구조로 받아져요.
학습 코드 · 참고 예시
from ultralytics import YOLO

# 사전학습된 분류 모델에서 출발
model = YOLO("yolo11n-cls.pt")

model.train(
    data="dataset",  # train/ val/ 이 있는 폴더
    epochs=20,       # 전체 데이터를 몇 번 반복할지
    imgsz=224,       # 분류 모델 기본 입력 크기
    batch=16,        # 한 번에 넣는 사진 수
)
내 모델로 추론 · 참고 예시
# 학습 중 가장 성능이 좋았던 가중치
model = YOLO("runs/classify/train/weights/best.pt")

results = model("test.jpg")
probs = results[0].probs

name = results[0].names[probs.top1]   # 1등 클래스
conf = float(probs.top1conf)           # 그 확률

결과 파일 · 지표위치어떻게 읽나
best.pt / last.ptruns/classify/train/weights/best는 검증 정확도가 가장 높았던 시점, last는 마지막 epoch. 실제로 쓸 땐 best.
results.pngruns/classify/train/loss는 내려가고 정확도는 올라가야 정상. train loss만 계속 내려가고 val이 멈추면 과적합이에요.
confusion_matrix.pngruns/classify/train/어떤 클래스를 어떤 클래스로 헷갈렸는지 보여 줘요. 대각선이 진할수록 좋아요.
top1 정확도학습 로그1등으로 고른 답이 맞은 비율. 분류 성능의 기본 지표예요.
top5 정확도학습 로그상위 5개 안에 정답이 있는 비율. 클래스가 5개 이하면 항상 1.0이라 의미가 없어요.

REVIEW

오늘 만난 오류

눌러서 원인과 해결을 펼쳐 보세요.

카메라 읽기 실패MSMF: can't grab frame. Error: -1072875772

원인Windows 카메라 앱이 웹캠을 쓰고 있었어요. 웹캠은 한 번에 한 프로그램만 쓸 수 있어요.

해결카메라·줌·팀즈·다른 파이썬 창을 모두 닫고 다시 실행.

DSHOW로 열기 실패DSHOW: can't be used to capture by index

원인설치된 OpenCV 5.0에서는 CAP_DSHOW로 번호(0) 카메라를 열 수 없어요.

해결기본값 cv2.VideoCapture(0) 그대로 사용.

"저장됨"이라는데 파일이 없음strftime("%Y/%m, %H:%M:%S")

원인윈도우 파일 이름에 /와 :는 쓸 수 없어요. imwrite는 실패해도 에러 없이 False만 돌려줘요.

해결"%Y%m%d_%H%M%S"로 변경하고, if cv2.imwrite(...)로 결과 확인.

이미지가 비어 있음(-215:Assertion failed) !_src.empty() in function 'cv::cvtColor'

원인cv2.imread("backg.jpg")가 파일을 못 찾아 None을 돌려줬어요. 실행 위치는 Wori 폴더, 사진은 capture_images/ 안에 있어요.

해결"./capture_images/backg.jpg"로 경로 수정, 바로 아래에 if img is None: 확인 추가.
